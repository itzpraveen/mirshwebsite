# Mirsh Systems Website

Static, responsive AI service company website for Mirsh Systems.

## Files

- `index.html` - page structure and content
- `styles.css` - layout, responsive styling, and motion
- `script.js` - navigation, reveal behavior, and mailto contact handling
- `assets/` - local generated images and favicon

Open `index.html` directly in a browser, or serve the folder with any static web server.
